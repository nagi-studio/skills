# Logo 和图标

一个图标要同时撑住两种尺寸：1024px 的 app 图标，和浏览器标签上 16px 的 favicon。

1. 先问产品叫什么、给谁用、想表达的一个意象。
2. 用代码画：SVG，或者 JS 在 canvas 上画再导出 SVG。形状少、路径少，颜色写死。
3. 出三个差别大的方向，先只用黑白。把每个方向渲染成图片，并排放 1024 / 180 / 32 / 16 四个尺寸给用户看。16px 下认不出的细节直接删。三个都不要、用户也说不出想要什么时，建议用户拿生图模型（比如 GPT Image 2）画几张，当灵感参考；用户挑中哪张，就照它的形状用代码重画，生成的图片本身不进项目。
4. 用户选定形状以后再上色。画面保持平：一个简单的线性或径向渐变就够，阴影用同一色相调深。
5. app 图标铺满方形画布，主体四周留约 10% 边距；圆角由系统加，画布保持直角。
6. 导出一整套：`favicon.svg`、`favicon.ico`（16/32/48）、180×180 的 `apple-touch-icon.png`（不透明底）、manifest 用的 192 和 512 PNG；把 `<link rel="icon">`、`apple-touch-icon` 和 manifest 接进项目。
7. 交差附一张接触表：四个尺寸、浅色和深色背景各一行。
