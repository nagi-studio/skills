# 用词对照表

改技术报告、实验记录、分析结论时按这份表逐条核。
左边是常见写法，右边是改法。例子取自一次实验报告的实际修改，
领域词换成当前任务的即可，改写手法不变。

## 1. 使用标准术语

已有通用说法的概念不要另造表述。

| 原写法 | 改为 |
| --- | --- |
| 超长度 / 超不超长度 | 截断 / 是否触及长度上限 |
| Ray 的端口会跟自己撞 | 多个任务的 Ray 抢占同一端口 |
| 臂 | 方案 |
| 只看长度那条线 | 长度启发式基线 |
| 刷奖励 | 奖励被优化但评测指标未改善 |
| 存档 | checkpoint |

## 2. 不发明比喻作为术语

需要读者推断指代对象的说法，改为直接说明。

| 原写法 | 改为 |
| --- | --- |
| 血统 | 基座来源 |
| 8 个不同血统 | 8 个不同基座的模型 |
| 那是尺寸差异，不是血统差异 | 原有区间由 Qwen 的 14B、32B、72B 构成，差异来自参数量而非基座 |
| 已经吃掉一半空间 | 已覆盖一半区间 |
| 变成了一个认题目的检索器 | 退化为问题识别，与学习价值无关 |
| 挑出来的题目看上去健康得多 | 选中问题的截断比例更低 |
| 误差范围还盖着基准线 | 置信区间与基线重叠 |

## 3. 表头和分类名使用中性名词

| 原写法 | 改为 |
| --- | --- |
| 坑 / 代价和教训 | 问题 / 影响 |
| 把握 | 确认程度 |
| 怎么做的 | 实验设置 |
| 重挑一次还剩多少重合 | 重采样后的重合率 |
| 有几种不同取值 | 取值数量 |
| 还在跑的 | 进行中 |
| 一个必须关掉的开关 | 需要关闭的过滤器 |

章节状态标签在一份文档里保持一致。前面用「已完成 / 已确认 / 未达到基线 / 结论待定」，
后面就不要出现「做通了 / 意外发现 / 需要修 / 没有买到想要的」，统一用前面那套中性标签。

## 4. 不使用「是 X，不是 Y」的对比句式

| 原写法 | 改为 |
| --- | --- |
| 梯度对齐：是噪声，不是信号 | 梯度对齐：三项检查结果均在噪声范围内 |
| 我们买到了血统上的多样性，但没有买到能力上的多样性 | 新增模型覆盖了更多基座，但正确率均低于原有区间下界 |
| 考法和用法对不上 | 评测口径为成对比较，与实际使用方式不一致 |
| 稳定是靠粗糙换来的 | 取值数量少的指标重合率高 |
| 越稳定的指标越挑不出东西，越挑得出东西的指标越不稳定 | 重合率与取值数量呈反向关系 |

## 5. 允许条目不包含数字或结论

部分条目可以只说明发生了什么。例如「对照组为随机选取的 32 个问题。」
这条内容已经完整，不需要继续补充其他方案与对照组的关系。

## 6. 未查明原因时直接写「原因未查明」

前文已经写明「原因未查明」时，后文不要继续补充未经验证的解释。

| 原写法 | 改为 |
| --- | --- |
| 这可能也解释了前文那个现象 | 该现象与截断的关系尚未验证 |

后续章节里已经查明机制并得到确认的内容可以保留。

## 7. 不使用口语词

| 原写法 | 改为 |
| --- | --- |
| 赢得很干脆 | 差值为 0.030 |
| 测得更准 / 测得更糙 | 估计精度更高 / 更低 |
| 可选的余地很小 | 候选范围小 |
| 基本上等于抓阄 | 接近随机选取 |
| 本来就分不出高下 | 真实差距低于可分辨范围 |
| 白跑 / 白占 | 无效运行 / 空占 |
| 不是白捡的 | 需要 79 GPU·小时 |
| 一个致命问题 | 主要问题 |
| 有事后找补的嫌疑 | 该切分方式在观察结果之后确定 |
| 原因不复杂 | 删除 |
| 既然预测这条路走不通，那就退一步 | 删除，直接进入实验设置 |

## 8. 不使用拟人表述

| 原写法 | 改为 |
| --- | --- |
| 天生需要几百到上千次采样 | 该信号所需的采样量为几百到上千次 |
| 一旦超就制造出参差 | 截断发生时会增大奖励方差 |
| 24 步训练只挪动 0.05 | 24 步训练后正确率变化为 0.05 |
| 超得越彻底反而越稳定 | 截断率越高，奖励方差越低 |
| 回答内容本身的好坏参差 | 答案质量的差异 |
